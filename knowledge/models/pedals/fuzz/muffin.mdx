The current target is the Electro-Harmonix V2 Ram's Head / Violet-era Muffin family. The modern Ram's Head reissue is useful for published impedance and control-behavior targets, but vintage units vary.

Do not treat "Muffin" as one canonical schematic. Triangle, Ram's Head, op-amp, Civil War, Green Russian, Black Russian, and modern NYC variants differ in values and sometimes topology. The op-amp Muffin is a separate topology, not a BJT variant.

## Baseline Assumptions

- Single 9 V supply rail.
- Four cascaded silicon NPN common-emitter stages.
- First stage: input booster and source-loading boundary.
- Middle two stages: clipping amplifiers with antiparallel silicon diodes.
- Tone stage: passive mid-scooped blend of low-pass and high-pass branches.
- Final transistor stage: recovery/output booster after tone-stack loss.
- True bypass is routing behavior, not part of the active circuit state.

## Published Boundary Targets

For the modern Ram's Head reissue/manual:

- input impedance target: 117 kOhm,
- nominal output impedance target: 25 kOhm,
- current draw target: about 2 mA at 9 V,
- tone clockwise increases treble and decreases bass,
- sustain controls sustain/distortion amount.

The current Rust model uses the 117 kOhm / 25 kOhm published boundary targets. The modeling priority is to match electrical boundaries first, then stage transfer curves, then variant voicing.

## Controls

- `sustain`: variable gain/drive feeding the two clipping stages.
- `tone`: 100 kOhm passive blend between low-pass and high-pass branches.
- `volume`: output attenuation after the recovery stage.
- `bypass`: routing state; active circuit state should remain private to the pedal instance.

## 2026-07-13 Greybound Free Promotion

Muffin is now a first-class pre-amp pedal in the Greybound Free profile. It
sits before the buffered Minotaur, preserving the intended high-impedance fuzz
input boundary when both pedals are enabled:

```text
Lumen (bypassed) -> Muffin (bypassed) -> Minotaur -> amp
```

The Free default leaves Muffin bypassed so existing Minotaur boost sessions do
not change on update. Its three controls initialise at `0.50`, putting the
photorealistic indicators at noon. The focused `rigs/muffin-nox.json5` preset
retains the denser voice (`sustain: 0.78`, `tone: 0.42`, `level: 0.46`) for a
dark-leaning Big Muff-style pad with long sustain. The UI maps these directly
to the existing Muffin controls (`sustain`, `tone`, and `level`) and its
footswitch changes the same slot bypass flag sent to the runtime.

The desktop runtime preserves one `DeviceSlotControls` entry per configured
device. This is required because the slot index is the control-routing key:
without the Muffin entry, downstream Minotaur controls would be applied to the
wrong processor and Muffin bypass would be ineffective. The Free runtime tests
assert both the default slot order and independent active Muffin/Minotaur
control values.

The pedal surface uses a project-owned 1970s fuzz-inspired enclosure asset at
`ui/assets/pedals/muffin@4x.png`, with static `IN`/`OUT` side jacks. Its
knobs, LED, and footswitch are separate photorealistic runtime assets; the LED
switches between dark ruby and lit ruby states with the same bypass state.

This promotion did not claim a circuit-accuracy result. The scalar baseline was
replaced on 2026-07-14 by the component-circuit candidate documented below;
the candidate still needs a matching hardware capture or full SPICE fixture
before it can claim component-exact accuracy.

Validation was regression-oriented against the existing model and used the
focused `rigs/muffin-nox.json5` integration rig:

```bash
target/release/greybound-cli --rig rigs/muffin-nox.json5 --input-wav "lab/references/tone3000-inputs/Brit - Guitar.wav" --output-wav target/muffin-nox-free-3s.wav --render-seconds 3 --sample-rate 48000 --period-size 16 --ir lab/references/tone3000-irs/celestion.wav --monitor --monitor-log target/muffin-nox-free-monitor.log
```

The render completed cleanly: zero input/output xruns, zero near clips, and
zero hard clips. The loudest observed output peak was `-1.2 dBFS`; RMS stayed
around `-11.2 dBFS` to `-11.5 dBFS`. Focused Rust coverage also passed the
Muffin sustain/impedance tests and the Free-profile routing/asset tests.

## External Boundaries

The pedal should receive and emit voltage plus impedance:

- input source: guitar pickup or previous pedal output,
- input load: Muffin input impedance plus cable capacitance memory,
- output source: pedal output voltage plus output impedance,
- output load: amp input, next pedal, or FX-loop return.

`ConnectionState` owns cable capacitance and source/load division. The pedal should not mutate arbitrary amp internals.

## 2026-07-14 Component-Circuit Candidate

`core/src/pedal/muffin.rs` now instantiates four reusable
`BjtCommonEmitterStage` cells from `core/src/circuit/muffin.rs`. Each stage
uses an incremental Shockley BJT current around a fixed quiescent current, a
bounded four-step Newton solve for the emitter, and explicit trapezoidal
emitter-bypass and collector-capacitor state. The two clipping pairs use a
bounded Shockley solve against the collector source resistance; they are no
longer a `tanh` applied after arbitrary gain.

The audio path runs the nonlinear circuit at 2x with the shared 33-tap
half-band FIR up/downsamplers. This preserves the one-sample pedal boundary
while suppressing folding from the diode and collector-saturation solves. The
collector node is limited by the explicit 9 V rail and its fixed DC operating
point before capacitor state is updated; rail-infeasible current assumptions
cannot become a long DC transient at the output.

The tone control is a four-node trapezoidal MNA network. It retains both
capacitor histories and includes Q3 source resistance plus Q4 base loading:

```text
Q3 collector -- Rs --+-- 39k --+-- 10n -- ground
                      |         |
                      +-- 3.9n -+-- 22k -- ground
                                \ 100k tone pot / --> Q4 base load
```

The candidate working values are a Ram's Head/Violet-era hypothesis, not a
universal Big Muff bill of materials:

- Q1/Q4: 39 kOhm collectors, 390 Ohm emitter resistors, 10 uF/1 uF bypass
  capacitors respectively, `0.12 mA` quiescent collector current, and 470 pF /
  2.2 nF collector smoothing capacitors.
- Q2/Q3: 100 kOhm collectors, 390 Ohm emitter resistors, 1 uF bypass
  capacitors, `45 uA` quiescent collector current, 2.2 nF collector smoothing
  capacitors, and antiparallel 1N4148-like pairs to ground.
- Tone stack: 39 kOhm/10 nF low path, 3.9 nF/22 kOhm high path, 100 kOhm pot.
- Input and output: 117 kOhm input load, 25 kOhm output boundary, both
  AC-coupled.

The `sustain` control currently moves the base drive made available by the two
clipping-stage shunt-feedback networks. This preserves a bounded component
solve while the exact taper and feedback resistors remain a variant-specific
measurement task.

## Stage Notes

Input booster:

- Public analysis identifies a shunt-feedback common-emitter input booster.
- One analyzed public value set uses RB 20.4 kOhm, RL 9 kOhm, RE 100 Ohm, RS 39 kOhm, and RF 470 kOhm.
- Confidence is high for role/topology and medium for exact values because variants differ.

Clipping stages:

- Two common-emitter stages with antiparallel silicon diode clipping.
- Diode target is a 1N914/1N4148-equivalent Shockley pair loaded by the stage
  collector resistance.
- Forward voltage target for vintage silicon parts is roughly 0.5 to 0.6 V, but measured curves are better than fixed constants.
- Current implementation is an incremental BJT plus diode solve. A future full
  DC MNA fixture can replace the fixed operating-point assumption.

Tone stack:

- Passive Muffin tone blend.
- Classic values used as the current target:
  - low-pass branch: 39 kOhm and 10 nF,
  - high-pass branch: 3.9 nF and 22 kOhm,
  - blend potentiometer: 100 kOhm.
- Implemented as a trapezoidal MNA passive network including source impedance
  and recovery-stage load.

Output recovery:

- Common-emitter transistor stage after the passive tone stack.
- Should model output coupling and volume-pot loading.
- Published output impedance note for the modern Ram's Head is nominally 25 kOhm.

## Remaining Implementation Plan

Keep `ElectricalSignal`, `Load`, and `ConnectionState` as the rig-level interface. The first reusable cells are now `BjtCommonEmitterStage`, `SiliconDiodePair`, and `MuffinToneStack`; they are scalar, deterministic, bounded, and non-allocating in the audio path.

Next, add the matching full SPICE fixture and test Q1-Q4 operating points,
Sustain taper, and pot taper against a selected public or project-owned
reference unit.

## Validation Gates

The model is not component-exact until:

- published/manual impedance targets match within useful tolerance,
- SPICE and Rust agree for individual stages (not yet available for Muffin),
- tone-stack response agrees at several tone positions,
- sustain changes harmonic density and compression correctly,
- guitar-source versus buffered-source input changes are audible and measurable,
- output level into 1 MOhm, 500 kOhm, 220 kOhm, and 100 kOhm loads behaves plausibly.

## Measurement Protocol

Hardware or SPICE captures should include:

- supply voltage and current draw,
- input impedance at 100 Hz, 1 kHz, 5 kHz, and 10 kHz,
- output impedance across volume positions,
- bypass behavior,
- potentiometer resistance/taper if a unit can be opened,
- Q1 collector, clipping-stage outputs, tone-stack input/wiper, recovery collector, and final output,
- sine tests at 82 Hz, 110 Hz, 220 Hz, 440 Hz, 1 kHz, 3 kHz, and 6 kHz,
- input amplitudes from 20 mV RMS to 1 V RMS, with large amplitudes only from a buffered source.

## NAM Validation Scope

The local source-safe manifest
`lab/references/nam/manifests/big-muff-v3-58283.json` records a public
TONE3000 A2 pedal-only reference: `BIG MUFF V3 T12 Sfull -18db`. It has no IR;
the matching Greybound rig is therefore `rigs/muffin-nam-reference.json5`,
which bypasses both amp and cab, uses the same Mayer DI, and applies `-18 dB`
input gain. The reference is a 1990s V3 Big Muff rather than the exact
Ram's-Head/Violet hypothesis, so it validates the BJT Muff family and the
capture setting, not component identity.

The fixed 48 kHz / three-second comparison is recorded in
`lab/experiments/008-muffin-component-circuit.md`. The current 2.2 nF
collector-smoothing candidate is `warning` rather than `severe`: gain alignment
is `-0.83 dB`, weighted guitar-band LSD is `19.37 dB`, maximum normalized
spectral-balance drift is `12.30 dB`, and there are zero near/hard clips. The
remaining mismatch is concentrated above 1 kHz, so it is a variant-voicing and
tone-stack/collector-capacitor fitting task rather than a numerical-health
failure.
