Amp model pages describe target amp families and how Greybound currently maps them into DSP. Reusable circuit-cell behavior belongs in `knowledge/circuits/`.

Current amp targets:

- Nox30, a circuit-informed amp model based on a JMI-era Top Boost style reference circuit.
- None Star Clean/Edge, a stage-level graybox target for boutique clean and edge-of-breakup 6L6 behavior.
- Daybreaker 50, a modern high-headroom clean/edge 6L6 target calibrated against an amp-head NAM reference.
- Boxer Seven Lead, a stage-level graybox target inspired by the Bogner Shiva 20th Anniversary lead channel.
